# Originalidad y referencias de género

Siete Raíces es un universo propio. Las misiones, regiones, personajes, nombres, diálogos, objetos y eventos de este repositorio se escriben para este proyecto.

La novela **El Emperador Mágico** y otras obras de cultivo pueden servir como referencia general de género para estudiar ritmos narrativos, progresión, rivalidades, misterios y variedad de aventuras. No se copian sus escenas, misiones, diálogos, personajes, nombres distintivos ni secuencias argumentales.

El contenido de esta fase se mantiene como `proposal` para que el responsable del universo pueda revisarlo y decidir qué pasa a canon.
